# 002. Один снимок в памяти SDK

Один цикл обновления загружает ответ с таймаутом и пределом 1 МиБ, проверяет контракт и собирает неизменяемые словари. Ссылка на снимок публикуется через `Volatile.Write` после всех проверок. Каждая оценка читает ссылку один раз, поэтому флаг и номер ревизии согласованы даже при обновлении.

На ошибке чтения SDK сохраняет снимок без ограничения по времени. При пустом кеше и отсутствующем флаге действует переданное значение. Дискового кеша нет. После восстановления БД из более старой копии уже работающий SDK примет снимок только с ревизией выше известной.

Таймер обновления и тайм-аут HTTP используют один `TimeProvider`. Ошибка синхронного наблюдателя `reportFailure` изолирована в точке его вызова, чтобы диагностика не могла остановить обновления.
