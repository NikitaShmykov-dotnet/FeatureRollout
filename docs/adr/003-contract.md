# 003. Публикация полного снимка

Маршрут `/v1/config/{environment}` и поле `schemaVersion` обозначают версию HTTP API и формат документа соответственно. Номер `revision` растёт независимо для каждого окружения. SDK проверяет схему, окружение и поля целиком перед активацией. Несовместимое изменение потребует поддержки нового формата у потребителей до его публикации.

Администратор отправляет полный набор флагов вместе с ожидаемой ревизией. Прямой SQL позволяет выразить проверку ревизии одним условным `UPDATE` в PostgreSQL. В той же транзакции добавляется строка с исходным JSON, оператором и временем публикации. Эта строка служит историческим снимком и записью аудита. У API нет операций изменения опубликованной строки. Формат `json` сохраняет байты сериализованного текста, поэтому ограничение размера проверяется для того же представления, которое скачивает SDK.
