# 001. Стабильная процентная группа

Вход SHA-256 состоит из четырёх байт длины ключа флага в big-endian, байтов ключа и байтов ID. Строки кодируются UTF-8 без нормализации. Префикс длины разделяет пары вроде `ab/c` и `a/bc`.

Первые восемь байт SHA-256 читаются как беззнаковое big-endian число. Остаток по модулю 10 000 даёт bucket от 0 до 9 999. Условие включения `bucket < percent * 100` даёт пустую группу для 0% и полную для 100%. При росте процента сохраняется исходная группа, если ключ, ID и правила перед rollout не изменились. Окружение в хеш не входит, поэтому один ключ даёт ту же группу во всех окружениях.
